Rules shared by every gallery in this repository. Read them before a design slice; they answer most of what a review would otherwise ask.

| Doc | What it answers |
| --- | --- |
| [Design principles](design-principles.md) | What good looks like: the ideology, containers, actions, type, platforms |
| [Done checklist](done-checklist.md) | What a design slice must include before it is shown |

| [Review rubric](review-rubric.md) | How a design review scores a product |

Product-specific rules are in each gallery's `AGENTS.md` (`augur-designs/`, `cogitator-designs/`).
