# Review rubric

Used by the Battle Augur design reviews of 2026-11-11 and 2026-11-12. Scale 0–10: 0 unusable; 5 functional with clear friction; 7 coherent with identifiable gaps; 9 thoroughly validated and platform fluent; 10 exceptional, evidence-backed.

| Criterion | Weight |
| --- | ---: |
| Android: Material 3 / Expressive (where the product runs on Android) | 15 % |
| Apple: iOS / iPadOS / macOS | 15 % |
| Windows | 10 % |
| Product ideology (fast access, declared actions, vertical space; equal thirds) | 40 % |
| Typography and readability in every theme | 20 % |

Normalise the weights over the criteria that apply to the product. Score per form factor, then combine by criterion.

**Evidence labels:** *Verified* (captures, code, measurements), *Inference*, *Proposal*, *Open*. State what was not done (no device run, no screen reader, guidance pages that could not be read). Scores are judgments with about ±1 point uncertainty, not measurements.

**Useful measures:** rows in view per screen, the position of the first control, row heights, contrast of text, borders and fills against the page.
